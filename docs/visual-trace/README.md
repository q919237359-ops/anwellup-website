# ANWELLUP category visual trace

This folder records the source hierarchy, invariants, final files and visual-QA decisions for the seven category entry assets used by the September 2026 website build.

- `product-truth.categories.json` records only visible or documented category-level facts. Category compositions are navigation imagery, not proof of a specific SKU, certification, facility or application claim.
- `brand-rules.json` separates website-level ANWELLUP branding from physical product identity. ANWELLUP marks must not be added to product packaging.
- `image-manifest.categories.json` records final output paths, hashes and QA disposition.
- Six generated category compositions were supplied as already reviewed and accepted for this website build.
- Carry + Shopping Bags uses the supplied real source image as the immutable master. Three generated attempts were rejected because the small red label text was distorted; none of those generated versions may be used.

Specifications displayed on the website are reference data from the existing project handoff and remain subject to written confirmation for the selected model, order configuration and destination market.
