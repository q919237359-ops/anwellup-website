# ANWELLUP 图片交付优化记录

执行日期：2026-09-07

## 结果

- 全站实际引用 33 张图片：32 张内容图片使用 WebP，1 张 PNG 仅作为兼容性 favicon。
- 六张 1448 × 1086 品类图片保留原 PNG 母版，网页交付版采用 WebP quality 92、smart subsampling。
- 六张品类交付图从 7,207,188 bytes 降至 519,416 bytes，减少约 92.8%。
- 品类图解码后 PSNR 为 45.20–46.81 dB；对细节最多的餐具图进行了原尺寸肉眼复核。
- 购物袋合成图和七张制造图片使用 lossless WebP，解码后与 PNG 逐像素一致，共减少 272,556 bytes（33.2%）。
- 页头与页脚使用的新品牌 Logo 转为 lossless WebP，逐像素一致，由 101,902 bytes 降至 43,954 bytes。
- 原 PNG 文件继续保留为来源证据和可回退母版，不作为页面内容图片加载。

## 自动检查

运行 `pnpm audit:images` 会扫描生产导出 HTML/XML 中实际引用的图片，汇总格式、体积、非 WebP 位图与缺失文件。构建后还会自动生成 `image-sitemap.xml`。

favicon 保留 PNG 是兼容性选择；这不影响正文图片传输，且该文件只在浏览器图标场景加载并长期缓存。
