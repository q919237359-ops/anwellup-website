## 本轮已修正

1. **横向区图片裁切**：原固定状态的图片框只有 `32dvh` 高，宽度可达 660 px，配合 `cover` 会明显裁掉 4:3 图片上下部分。现按 4:3 保留图片框，固定状态的卡片宽度随视口高度调整，图片使用 `contain`。
2. **购物袋展示**：首页与其他产品页保持相同原则，白底、完整图片，最大宽度不超过原图 550 px。
3. **悬停反馈**：产品本体保持完整，反馈放在链接箭头上。
4. **动效异常恢复**：先注册清理函数再初始化动画；中途出错时恢复样式，退出页面取消待执行的刷新。
5. **固定区位置**：固定起点读取导航实际高度，减少导航尺寸变化后的遮挡风险；图片加载引发的重新测量合并到同一帧。
