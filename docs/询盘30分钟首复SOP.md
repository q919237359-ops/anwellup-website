# ANWELLUP 询盘 30 分钟首复 SOP

## 处理规则

1. 新 WhatsApp 或网站询盘进入值班手机后，30 分钟内先确认收到；完整报价未完成也必须首复。
2. 首复只追问报价必需信息，不一次抛出长问卷。
3. 记录收到时间、首复时间、来源 UTM、产品/ANWELLUP SKU、国家、数量档与当前状态。
4. 网站公开时效只承诺团队能够长期稳定做到的范围。
