# ANWELLUP 流量增长 90 天执行方案

本方案于 2026-09-07 从旧任务记录中找回，并按《独立站建站后快速起流量实操手册》与当前线上版本重新校准。执行顺序固定为：**可发现 → 可度量 → 可相信 → 可转化 → 主动导流 → 内容复利**。

## 当前判断

- 已完成：Next.js 静态导出、正式域名与 HTTPS、可抓取独立 URL、robots、sitemap、canonical、基础 Organization/WebSite 结构化数据、产品内链、WhatsApp RFQ。
- 本轮落地：GTM/Clarity 安装接口与转化事件、IndexNow 发布通知、图片 sitemap、图片格式审计、WebP 优化、执行台账、询盘首复 SOP。
- 需要账号后才能验收：Google Search Console Domain Property、Bing Webmaster、GTM 容器、GA4 属性、Clarity 项目、UptimeRobot 监控。
- 需要真实经营数据后才能发布：认证编号、产能、MOQ/价格区间、打样与交期统计、客户案例和独立数据资产页。不得编造。

## 第 1–7 天：72 小时基线与收录

1. 部署本轮技术更新，确认全部正式 URL、robots、普通 sitemap、图片 sitemap 与 IndexNow key 均返回 200。
2. 创建 GSC Domain Property，在 DNS 添加真实 TXT 值；提交 `https://anwellup.com/sitemap.xml` 与 `https://anwellup.com/image-sitemap.xml`。
3. 创建或从 GSC 导入 Bing Webmaster，提交两个 sitemap；每次发布由 GitHub Actions 自动通知 IndexNow。
4. 在 GitHub Repository Variables 填入 `NEXT_PUBLIC_GTM_ID` 与 `NEXT_PUBLIC_CLARITY_ID`，再部署并逐个验收事件。
5. GTM 中连接 GA4，验证 `whatsapp_click`、`inquiry_open`、`add_to_inquiry`、`remove_from_inquiry`、`catalog_download`、`product_search`、`category_filter`。
6. UptimeRobot 监控首页、`/sitemap.xml`，测试一次告警。
7. 保存 GSC/Bing 收录数、GA4 事件、Clarity 首条录屏、核心 20 个采购词与 20 个 AI 买家问题的零点快照。

## 第 1–30 天：承接与主动导流

- 询盘必须在 30 分钟内首复；使用 `询盘30分钟首复SOP.md`。
- 邮件签名、目录 PDF、WhatsApp 话术、展会二维码和允许放站外链接的平台全部使用固定 UTM。
- UTM source 只用：`whatsapp`、`email-sig`、`cold-email`、`catalog-pdf`、`alibaba`、`tradeshow`、`parcel-insert`、`linkedin`、`youtube`、`reddit`。
- 先把现有客户、报价单和目录访问导向具体品类页，不统一导向首页。
- LinkedIn 公司页与业务员个人页的公司名、电话、网址保持逐字一致；每天做精准互动，不群发垃圾私信。
- 不投广告，直至真实统计可用、询盘字段与响应 SOP 验收完成。

## 第 8–60 天：第一个内容集群

先做 `Takeaway Boxes + Containers`，不同时铺七个薄集群：

- 1 个支柱页：现有品类页持续扩充真实选型信息。
- 3 个交易/决策页：custom takeaway containers、hinged vs folded containers、how to choose takeaway packaging。
- 3 个问题页：MOQ、样品与打样、交期与装箱。
- 2 个场景页：restaurant chains、prepared-food retail。
- 1 个验厂页：how to verify a food-packaging supplier。

每页必须满足：一个明确词簇；问题式 H2；前 1/3 有直答；真实作者/审核者；至少 3 条正文内链；任何数字都注明样本、时期与来源。没有真实数据时只做内容 brief，不上线水文。

## 第 31–90 天：站外实体与机会词循环

- LinkedIn Pulse 每周 1 篇，基于站内内容重写并加入真实业务视角。
- YouTube 每月 1–2 条真实工厂/流程视频，含英文字幕、章节、规格说明和带 UTM 的对应页面链接。
- 目录只提交与业务和地区匹配的平台，所有 NAP 与公司事实使用统一信息卡。
- Reddit 只做真实答疑；禁止马甲自吹和机械发链接。
- GSC 有数据后，每周筛选 position 8–20 且 impressions >100 的查询：改 title、补问答块、加 3 条内链、补真实数据与结构化表格、发布后通知 IndexNow，两周复测。

## KPI 与回滚线

- 收录率：第 14 天目标 >80%，成熟后 >95%。
- 移动端真实 LCP：目标 <2.5s；达到后不为分数删除工厂实拍。
- 询盘转化率：<1% 时先修信任与页面，不加预算。
- 首次响应：内部目标 30 分钟；公开承诺以实际可持续能力为准。
- 禁止批量外链包、虚假评论、未授权客户 Logo、虚构认证/数字、AI 批量水文和无母语维护的机翻站。
